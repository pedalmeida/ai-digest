Decision Models Market Standardizes: Jev, OpenAI, Google

Jev launched a System One decision model API earlier this year. OpenAI released GPT-6 Luna Decisions in October. Today Google completes the consensus with an API so similar Simon Willison notes it even reuses Jev's terminology. The spec covers yes/no questions (Jev's 'Noul'), multi-choice, and rubric-based scoring. All three are priced equivalently.

What changed

Google joins with identical API, completing three-vendor standardization.

Key signals
  • ◆Google's Decisions API mirrors Jev's spec: yes/no, choice, and rubric-scoring questions
  • ◆Three major vendors now offer deterministic decision APIs at identical pricing tiers
  • ◆Identical API interface reduces switching costs and accelerates adoption across tools
What this means for you

Decision models are now a standardized primitive across vendors, not a differentiator. For Portuguese SMBs, this means you can build deterministic workflows (loan approvals, content classification, routing) confident the API won't disappear if you switch platforms.
