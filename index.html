Agent-based tasks use 10 to 50 times more tokens than simple chat prompts.

🔴 Urgent
04
Story thread · new
Agents burn 10-50x more tokens per task than chat; cost accounting must change

As agents become more sophisticated, they generate far more internal tokens than human-visible outputs. A single user request to an agent triggers planning, multiple code generation attempts, test runs, and self-correction loops. This hidden token consumption is invisible to clients but destroys margins if you're pricing by token.

What changed

MIT piece published; makes explicit what builders are discovering: token counting is dead for agent pricing.

Key signals
  • ◆A single task involves planning, code generation, testing, iteration cycles
  • ◆Token count is no longer the right metric for measuring agent costs or value
  • ◆The more useful an agent becomes, the more expensive it gets per visible unit of work
What this means for you

Your agency likely quotes clients based on per-token pricing or fixed-scope projects. If agents require 20x more tokens to complete the same task, your cost structure is wrong. You need a new pricing model that counts 'tasks shipped' not 'tokens consumed.' This is urgent.

The internet is now navigable by autonomous AI agents, fulfilling 25-year-old vision.

🟢 Apply now
08
Story thread · new
Agentic web arrives: Tim Berners-Lee's 2001 Semantic Web vision now real via autonomous agents

In 2001, Tim Berners-Lee proposed the Semantic Web: an internet where software agents could understand and act on information autonomously. It failed because it required every website to tag content with machine-readable metadata. Now, 25 years later, the agentic web is arriving, but via a different path: frontier LLMs can understand human-readable web content, and tools like browser-use let agents interact with web UIs directly.

What changed

MIT piece articulates what builders have been shipping for months: agents are now reliably using the web to accomplish real tasks.

Key signals
  • ◆Agents can browse, understand, and act on web pages without human mediation
  • ◆MCP (Model Context Protocol) and browser-use APIs enable agent-to-web interaction at scale
  • ◆Semantic Web failed; agentic web succeeds because agents understand context implicitly
What this means for you

This is the infrastructure layer for your next wave of agency services. Clients will ask you to build agents that navigate their suppliers' APIs, monitor competitors, execute trades, schedule meetings. All of this is now possible. The tooling (browser-use, MCP servers) is real. You can build these workflows now.
