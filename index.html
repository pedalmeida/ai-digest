Running Agent Code Safely in Isolated Sandboxes

Agent systems are increasingly running code on user machines. The safety question is: what stops a compromised agent from deleting files, stealing data, or breaking the system? Sandboxing is the proven answer.

What changed

Willison and Prime Radiant published full write-up with working demos showing three different sandbox strategies. This is actionable, not theoretical.

Key signals
  • ◆Three sandbox options published: WebAssembly, QEMU (virtual machine), and Apple Container isolation
  • ◆Prevents agents from damaging your Mac even if misdirected or prompt-injected
  • ◆Demonstrated with Claude Code, Superpowers, and other agent systems; working demos included
What this means for you

If your agency runs agents for clients or on client machines, this solves a major liability risk. You can safely let agents execute code without worrying about system damage. Worth testing with one client project this week to build confidence.

Recommended action

test, because isolating agent code execution is critical for client trust and your agency's insurance and liability.

Why this made the cut: Only concrete safety pattern for running agents on client machines published this week; directly applicable to agency delivery.

Enterprise Agents Moving from Chatbots to Workflow Orchestrators

Enterprise use of agents is maturing from Q&A systems to autonomous workflow executors. This is a mental model shift: agents as workers, not assistants.

What changed

Levie published new post explicitly naming this shift. Previous thinking treated agents as answer engines; now they're task coordinators.

Key signals
  • ◆Phase 1 (past): Agents that spit out quick answers for users
  • ◆Phase 2 (now): Agents you orchestrate inside a set of tasks, fan out to sub-tasks, work in parallel
  • ◆Token spend per employee continues rising; adoption curve remains early
What this means for you

This means your agency should focus on building agents that AUTOMATE work (not just answer questions). Think: an agent that checks approvals, pulls documents, runs checks, and reports back — not an agent that answers 'what is my budget?'. This is how PT SMBs will get ROI.

Recommended action

investigate, because your client pitches should shift from 'agent that answers questions' to 'agent that completes workflows.'

Why this made the cut: Clear signal about how enterprise AI work is maturing; directly impacts agency positioning.
