Story thread · new
Decision models become API category (Gemini Decisions joins Jev, OpenAI)

Decision models represent a shift from unstructured reasoning to structured choice-making. They're not replacing reasoning models; they're a complement for tasks where you need deterministic output.

What changed

Jev and OpenAI released decision APIs in September/October; Google entered category today.

Key signals
  • ◆Google Gemini Decision 1 mirrors Jev's API; same question types, same pricing (roughly $0.10/1M input tokens)
  • ◆Pattern: structured decision-making is becoming a standard interface, like webhooks or OAuth
  • ◆Use case: agents need to make deterministic choices (categorize, evaluate, score) without hallucination
What this means for you

This matters for your agency's SMB clients who need reproducible categorization or scoring. Instead of prompt engineering, you can use a decision model API and guarantee consistent results. Useful for routing (which team handles this?), qualification (is this lead worth $X?), or grading (how bad is this defect?). Build this into your service delivery model—clients will pay for certainty.

Recommended action

investigate, which decision model API has the best latency and accuracy for your common SMB use case (e.g., lead scoring)

Why this made the cut: category emergence signals market maturation; new revenue pattern for agency
