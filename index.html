Claude Code VS Code Extension Compromised

An attacker compromised the official Claude Code extension on the VS Code Marketplace, injecting code that collected credentials and environment variables from developer machines. The attack affected any developer who installed or auto-updated the extension.

What changed

Security researchers and multiple outlets (Wired, Hacker News) have now independently confirmed the backdoor was live and actively distributed before removal.

Key signals
  • ◆Backdoor in official Cursor Marketplace: Attackers compromised the Claude Code extension, distributing malware to VS Code users
  • ◆Supply chain attack vector: Attackers leveraged marketplace trust to reach developer environments at scale
  • ◆Wired and security researchers confirmed: Multiple outlets independently reported the incident; remediation underway
What this means for you

If you or your clients use Claude Code in VS Code, verify the extension is uninstalled and check for unauthorized access to credentials or project files. This is a direct threat to your agency's development workflow and client codebases.

Recommended action

investigate immediately — verify your extension list, check for suspicious activity in project repos, and advise all team members to audit their machines.

investigate — audit your current agent permissions model for each client. Document what each agent can access, who approved it, and how you log and review its actions.
